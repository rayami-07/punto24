# Punto 24

Mapa de puestos y negocios locales de Cuautitlán Izcalli (piloto).

**Dirección pública: https://rayamipunto24.web.app** (Firebase Hosting del proyecto `punto24-rayami`, sitio `rayamipunto24`). La copia de GitHub Pages redirige ahí.
Leaflet + OpenStreetMap. Sin base de datos ni login.

- `vendedores.js`: aquí se editan los pines a mano.
- `config.js`: centro del mapa, giros, mensajes, URL y crédito de las teselas.
- Modo revisión: agrega `?revisar=1` a la dirección.
