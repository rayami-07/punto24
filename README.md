# Punto 24

Mapa estático de puestos y negocios locales de Cuautitlán Izcalli (piloto).
Leaflet + OpenStreetMap. Sin base de datos ni login.

- `vendedores.js`: aquí se editan los pines a mano.
- `config.js`: centro del mapa, giros, mensajes, URL y crédito de las teselas.
- Modo revisión: agrega `?revisar=1` a la dirección.
